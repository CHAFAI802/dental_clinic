## Remplacer une photo

1. Déposer le nouveau fichier dans ce dossier (`frontend/public/images/`).
2. Soit modifier le chemin dans `src/config/siteConfig.js`,
   soit — sans toucher au code — coller le nouveau chemin dans
   **/settings/site → Images** (ou les photos dans **Contenus textuels → Équipe**).

Une URL vide dans la configuration fait revenir automatiquement l’illustration
vectorielle par défaut aux couleurs du thème.
